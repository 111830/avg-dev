# Tools and Environment

> For learning `js`, why not get some help by choosing a good IDE, compiler, and some useful extensions.

## Tools I chose
- **VS Code** — As an editor we could also go with `Neovim`, but for now I'm still a beginner in Neovim. I do use Vim mode inside VS Code, so it feels the same, while I keep practicing pure Vim and Neovim on the side.

- **Quokka.js** — Shows the output right next to each `console.log`. It's like running `node file_name.js` in the terminal, but in a much easier way.

- **Node.js** — And of course, for executing JS outside the browser.
